# paint-by-numbers

Програма автоматичного створення картин за номерами з фотографій (див. ТЗ версії 2.0).
Без ШІ: лише класичні детерміновані алгоритми, працює без інтернету.

**Статус: етапи 1--2 (консольний запуск).** Є векторне планарне розбиття зі спільними ребрами та SVG.
PDF, специфікація ємностей і каталог фарб будуть на етапах 4--5.

## Запуск

```bash
uv sync                     # або: pip install -r requirements або залежності з pyproject.toml
uv run python main.py photo.jpg -o out --mode balanced --colors 24 --width-mm 300
```

Параметри: `--mode simple|balanced|detailed`, `--colors 4..64`, `--width-mm`, `--height-mm`
(якщо не задано, береться за пропорціями фото; при невідповідності фото кадрується по центру),
`--px-per-mm` (робоча роздільна здатність), `--seed` (для відтворюваності).

## Результат у папці `out/`

- `color_preview.png` --- кольоровий еталон
- `canvas_outline.svg` --- векторний контурний макет у мм (кожна спільна межа один раз, номери всередині ділянок)
- `contour_preview.png` --- растеризація саме векторних контурів з номерами
- `palette.png` --- палітра з номерами
- `compare.png` --- оригінал | еталон | контури
- `report.json` --- кількість ділянок, ділянки без місця для номера, вузькі ділянки, перевірка топології, ΔE, SSIM, час

## Конвеєр етапу 1

завантаження (EXIF) → згладжування зі збереженням меж → K-Means у Lab (фіксований seed) →
зв'язні області → граф сусідства → об'єднання малих і вузьких областей (з урахуванням карти
значущості та контрасту) → прибирання виступів вужчих за мінімальну ширину → планарне розбиття:
ребра між областями згладжуються й спрощуються з нерухомими вузлами → перевірка топології (грані =
області, немає перетинів, сума площ = площа полотна) → номери в полюсі недоступності (polylabel) → SVG.

Числа порогів у `paint_by_numbers/settings.py` --- стартові гіпотези з ТЗ (розділ 6.4), їх треба
уточнити фізичними тестами.
